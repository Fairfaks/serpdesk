Если macOS пишет, что SerpDesk «повреждён»
================================================

1. Перетащите SerpDesk.app в папку «Программы» (Applications).
2. Откройте приложение «Терминал» через поиск Spotlight.
3. Напечатайте в Терминале:

   zsh

   После zsh должен остаться один пробел. Enter пока не нажимайте.
4. Перетащите файл «Разблокировать SerpDesk.command» из окна DMG в окно
   Терминала — путь к файлу подставится автоматически.
5. Нажмите Enter.

Помощник проверит системный идентификатор SerpDesk, снимет карантинную метку
только с /Applications/SerpDesk.app и запустит программу. Защита macOS для
остальных приложений останется включённой.

Не запускайте файл .command двойным кликом: Finder блокирует командные файлы,
которые находятся внутри загруженного из интернета DMG.
