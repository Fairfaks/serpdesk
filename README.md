# SerpDesk — десктопный съёмщик позиций (Mac + Windows)

Аналог TopSite/Wordchecker: проекты → фразы → съём позиций Яндекс и Google через
API [XMLRiver](https://xmlriver.com), история в SQLite, цветная сетка с дельтами,
экспорт CSV, автопроверка по расписанию. Electron, без нативных модулей.

[Скачать последнюю версию SerpDesk](https://github.com/Fairfaks/serpdesk/releases/latest) · Telegram автора: [@kakao_seo](https://t.me/kakao_seo)

Возможности сверх базового съёма:
- **Дочекивание ошибок** — перепроверка только фраз с «!» из последнего прогона, без оплаты полного круга;
- **Частотность Вордстат** (Wordstat New API, по региону проекта) — колонка с сортировкой; галочка в модалке добавления фраз;
- **Целевые URL** — «фраза; URL» при добавлении или через ⌖ на строке; если ранжируется другая страница, позиция подсвечивается оранжевым пунктиром, смена URL между проверками помечается ◆;
- **График динамики** по фразе — клик по фразе или 📈;
- **Импорт истории** из XLSX/CSV (RUSH Analytics, Топвизор и совместимые выгрузки);
- **Виртуальная таблица** — в DOM находятся только видимые строки и даты; старая история загружается страницами по 20 проверок;
- **Оценка стоимости до запуска** и журнал фактических запросов/расходов XMLRiver;
- **Поиск, сортировка** (по фразе/частоте/любому столбцу дат), **группы-теги** с фильтром-чипсами;
- дельта средней позиции считается только по фразам, найденным в обоих прогонах (без «парадокса средней»);
- **Реальная статистика ПС**: Яндекс.Вебмастер API + Google Search Console (сервисный аккаунт) — колонки Показы/Клики/Поз.ПС за 28 дней на вкладках соответствующих поисковиков, автопривязка сайта по домену; кнопка «⟳ ПС», настройка — см. [docs/GSC-YAVM-manual.md](docs/GSC-YAVM-manual.md);
- **«УРА, ПОБЕДА!»** — по завершении проверки всплывает окно с мемом и звуком; ролик зашит в приложение локально (`assets/victory.mp4`, YouTube не нужен), окно закрывается само; выключается галочкой в настройках.

## Аналитика (виды проекта: Позиции · Изменения · Динамика · Сравнение · Конкуренты)

- **Изменения** — частотно-взвешенная видимость, ТОП-3/10/30/100, важные падения, входы в ТОП-10, смены URL, нецелевые страницы, группы запросов и возможная каннибализация. Значимые ухудшения могут приходить системным уведомлением.
- **Динамика** — графики по датам: Динамика ТОП (% фраз в ТОП-3/5/10/30), Средняя позиция, Видимость (по CTR-кривой), Трафик-прогноз (частотность × CTR). Плюс два инсайта, которых нет у аналогов:
  - **«Где недобираем трафик»** — фразы, отсортированные по потенциалу визитов при выходе в ТОП-3;
  - **«Позиция есть — кликов нет»** — хорошая позиция XMLRiver, но реальный CTR из GSC/ЯВМ вдвое ниже нормы → проблема заголовка/сниппета.
- **Сравнение** — два прогона → карточки выросло/упало/вошло/выпало + списки с движением позиций.
- **Конкуренты** (opt-in) — домены-конкуренты снимаются из той же выдачи; таблица «Вы vs конкуренты», красная обводка где конкурент выше. С конкурентами ранняя остановка отключается (дороже).
- **Мобайл + десктоп** (opt-in) — режим устройства на проект (десктоп / мобайл / оба); при «оба» снимаются обе выдачи, в шапке — переключатель 🖥/📱.
- **Отчёт** — кнопка «Отчёт»: цветная сетка + KPI в отдельном окне, «Сохранить PDF / Печать».
- **Перенос базы** — в настройках экспорт/импорт всей базы одним .sqlite (Mac↔Windows).
- **Автообновления** — electron-updater + GitHub Releases; проверка при старте и в меню. Настройка — [docs/AUTOUPDATE.md](docs/AUTOUPDATE.md).

## Источники данных (и их цена)

| Источник | Эндпоинт | Глубина | Цена (тариф Базовый) |
|---|---|---|---|
| Яндекс Search API | `/yandex/xml` | топ-100 **одним запросом** (`groupby=...groups-on-page=N`) | 28 ₽/1000 |
| Яндекс лайв | `/search_yandex/xml` | 10 позиций на запрос, пагинация `page=0,1,…` | 25 ₽/1000 |
| Google | `/search/xml` | всегда 10 на страницу (с 09.2025), пагинация `page=1,2,…` | 25 ₽/1000 |
| Wordstat New | `/wordstat/new/json` | частотность фразы (`popular[0]`), параметр `regions` | 25 ₽/1000 |

Старый Wordstat API (`/wordstat/json`) мёртв: «Сбор старого вордстата больше не доступен».

Проверка листает страницы **с ранней остановкой**: как только домен найден — глубже
не запрашиваем. Глубина настраивается в проекте (ТОП-10/20/30/50/100).

Ошибки XMLRiver: 15 = «нет результатов» (не ошибка), 110/111 = заняты каналы (ретрай
с паузой), 115/HTTP 429 = перебор потоков (стоп на 10 минут), 200 = кончился баланс,
102–108 = неверные параметры проекта (стоп прогона), «Выполните перезапрос» = ретрай ×3.

## Данные

SQLite-файл: `~/Library/Application Support/SerpDesk/serpdesk.sqlite` (macOS),
`%APPDATA%/SerpDesk/serpdesk.sqlite` (Windows). Держит настройки (user/key XMLRiver),
проекты, фразы и всю историю проверок.

## Разработка

Node 22 (на этом Mac лежит в комплекте Screaming Frog):

```bash
export PATH="$HOME/.ScreamingFrogSEOSpider/node/5.1/node/bin:$PATH"
cd serpdesk
npm install
npm start          # запуск приложения
npm test           # тесты парсера/матчера (test/parse.test.js)
npm run dist:mac   # сборка dmg+zip (arm64)
npm run dist:win   # сборка setup+portable (x64)
```

`renderer/` открывается и в обычном браузере (мок-режим с демо-данными) — удобно
править вёрстку без Electron: `python3 -m http.server --directory renderer`.

## Структура

- `main.js` — главный процесс: окно, IPC, планировщик автопроверки, CSV, журнал расходов и уведомления
- `lib/analytics.js` — сравнение прогонов, видимость и важные сигналы
- `lib/costs.js` — верхняя оценка запросов и стоимости проверки
- `lib/xmlriver.js` — клиент API: URL-ы, разбор XML, классификация ошибок, punycode-матчер доменов
- `lib/checker.js` — прогон: пул воркеров по фразам, пагинация с ранней остановкой, ретраи
- `lib/db.js` — sql.js (SQLite-wasm), атомарная запись с дебаунсом
- `renderer/` — интерфейс (vanilla JS, тёмная тема)
