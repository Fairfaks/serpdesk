# SerpDesk — десктопный съёмщик позиций (Mac + Windows)

Аналог TopSite/Wordchecker: проекты → фразы → съём позиций Яндекс и Google через
API [XMLRiver](https://xmlriver.com), история в SQLite, цветная сетка с дельтами,
экспорт CSV, автопроверка по расписанию. Electron, без нативных модулей.

[Скачать последнюю версию SerpDesk](https://github.com/Fairfaks/serpdesk/releases/latest) · Telegram автора: [@kakao_seo](https://t.me/kakao_seo)

Возможности сверх базового съёма:
- **Дочекивание ошибок** — перепроверка только фраз с «!» из последнего прогона, без оплаты полного круга;
- **Частотность Вордстат** (Wordstat New API, по региону проекта) — колонка с сортировкой; галочка в модалке добавления фраз;
- **Целевые URL** — «фраза; URL» при добавлении или через ⌖ на строке; если ранжируется другая страница, позиция подсвечивается оранжевым пунктиром, смена URL между проверками помечается ◆;
- **График динамики** по фразе — клик по фразе или 📈;
- **Импорт истории** из XLSX/CSV (RUSH Analytics, Топвизор и совместимые выгрузки);
- **Виртуальная таблица** — в DOM находятся только видимые строки и даты; прокрутка проверена на 50 000 фраз, старая история загружается страницами по 20 проверок;
- **Проекты сгруппированы по домену** — группы сворачиваются, а состояние сохраняется между запусками;
- **Новые проверки слева** — в сетке позиций даты показаны от новых к старым, дельта сравнивается с предыдущим замером справа;
- **Оценка стоимости до запуска** и журнал фактических запросов/расходов XMLRiver;
- **Гибкое обновление** — перед запуском можно выбрать Яндекс, Google или оба поисковика; частотность Wordstat переснимается отдельно для всех фраз или только для пустых;
- **Досбор прерванной проверки** — готовые результаты сохраняются, а отсутствующие и ошибочные фразы можно дособрать в тот же столбец без повторного расхода на уже проверенные запросы;
- **Дублирование проекта** — настройки уже заполнены, остаётся выбрать новый регион, поисковики и перенести все, выделенные или новые запросы;
- **Поиск по фразам** — режим «Содержит» для слова или части фразы и «Точно» для полного совпадения; сортировка по фразе/частоте/любому столбцу дат, группы-теги с фильтром-чипсами;
- **Сворачиваемые данные аналитики** — позиции видны сразу, а столбцы ЯВМ, GSC и Метрики по умолчанию скрыты и раскрываются одной понятной кнопкой над таблицей;
- **Массовые операции с запросами** — выделение чекбоксами, выбор всего отфильтрованного списка, копирование и удаление;
- **Релевантная страница из выдачи** — клик по позиции открывает фактический URL для выбранной даты;
- **Блоки Яндекса (бета)** — для лайв-выдачи можно включить рекламу, колдунщики, карусели, новости, товарные блоки и приблизительное визуальное место. Органическая позиция остаётся основной; полнота зависит от ответа XMLRiver. Подробнее: [docs/BETA-SERP-FEATURES.md](docs/BETA-SERP-FEATURES.md);
- дельта средней позиции считается только по фразам, найденным в обоих прогонах (без «парадокса средней»);
- **Реальная статистика ПС**: необязательные подключения Яндекс.Вебмастера, Google Search Console и Яндекс Метрики. Вебмастер/GSC добавляют показы, клики и среднюю позицию, Метрика добавляет визиты, пользователей, отказы и цели по раскрытым поисковым фразам. Кнопка «⟳ Данные», настройка — см. [docs/GSC-YAVM-manual.md](docs/GSC-YAVM-manual.md);
- **«УРА, ПОБЕДА!»** — по завершении проверки всплывает окно с мемом и звуком; ролик зашит в приложение локально (`assets/victory.mp4`, YouTube не нужен), окно закрывается само; выключается галочкой в настройках.

## Аналитика (виды проекта: Позиции · Изменения · Динамика · Сравнение · Конкуренты · Регионы β)

- **Изменения** — частотно-взвешенная видимость, ТОП-3/10/30/100, важные падения, входы в ТОП-10, смены URL, нецелевые страницы, группы запросов и возможная каннибализация. Значимые ухудшения могут приходить системным уведомлением.
- **Динамика** — графики по датам: Динамика ТОП (% фраз в ТОП-3/5/10/30), Средняя позиция, Видимость (по CTR-кривой), Трафик-прогноз (частотность × CTR). ТОП-5 включён в график и вынесен в сводные карточки. Дополнительно:
  - **Динамика страниц** — пять самых быстрорастущих и падающих URL по изменению видимости между последними проверками;
  - **Заметки на графике** — ручные отметки изменений на сайте, релизов и апдейтов поисковиков;
  - **«Где недобираем трафик»** — фразы, отсортированные по потенциалу визитов при выходе в ТОП-3;
  - **«Позиция есть — кликов нет»** — хорошая позиция XMLRiver, но реальный CTR из GSC/ЯВМ вдвое ниже нормы → проблема заголовка/сниппета.
- **Сравнение** — два прогона → карточки выросло/упало/вошло/выпало + списки с движением позиций.
- **Конкуренты** (opt-in) — домены-конкуренты снимаются из той же выдачи; таблица «Вы vs конкуренты», красная обводка где конкурент выше. С конкурентами ранняя остановка отключается (дороже).
- **Регионы β** — необязательное сравнение средней позиции, доли фраз в ТОП-10 и видимости между проектами одного домена. Вкладка появляется только когда таких проектов минимум два.
- **Мобайл + десктоп** (opt-in) — режим устройства на проект (десктоп / мобайл / оба); при «оба» снимаются обе выдачи, в шапке — переключатель 🖥/📱.
- **Отчёт** — кнопка «Отчёт»: цветная сетка + KPI в отдельном окне, «Сохранить PDF / Печать».
- **Резервные копии и перенос базы** — SerpDesk хранит 14 ежедневных автокопий с восстановлением; в настройках также есть ручной экспорт/импорт одного .sqlite (Mac↔Windows).
- **Диагностика для поддержки** — одной кнопкой сохраняет версии, состояния запусков, расходы и последние ошибки; ключи, токены и пароли в файл не попадают.
- **Обновления с GitHub** — проверка при старте и в меню; Windows устанавливает обновление автоматически, неподписанная macOS-сборка открывает страницу скачивания. Для полной автоустановки на Mac нужен Apple Developer ID. Подробности — [docs/AUTOUPDATE.md](docs/AUTOUPDATE.md).

## Дистрибутивы (папка `dist/`)

| Файл | Платформа |
|---|---|
| `SerpDesk-1.5.10-mac-arm64.dmg` | macOS (Apple Silicon) |
| `SerpDesk-1.5.10-win-x64-setup.exe` | Windows-инсталлятор |
| `SerpDesk-1.5.10-win-x64-portable.exe` | Windows portable (без установки) |

Сборки не подписаны сертификатами: macOS при первом запуске скачанного файла может
сообщить, что приложение повреждено. В таком случае сначала перетащите SerpDesk в
«Программы». Затем откройте **Терминал**, напечатайте `zsh` и пробел, перетащите
в его окно файл **«Разблокировать SerpDesk.command»** из DMG и нажмите Enter.
Двойной клик по загруженному `.command` Finder блокирует, поэтому в DMG также
лежит текстовая пошаговая инструкция. Помощник проверяет идентификатор приложения
и снимает карантин только с SerpDesk. Windows SmartScreen может потребовать выбрать
«Выполнить в любом случае».

## Источники данных (и их цена)

| Источник | Эндпоинт | Глубина | Цена (тариф Базовый) |
|---|---|---|---|
| Яндекс Search API | `/yandex/xml` | топ-100 **одним запросом** (`groupby=...groups-on-page=N`) | 28 ₽/1000 |
| Яндекс лайв | `/search_yandex/xml` | 10 позиций на запрос, пагинация `page=0,1,…` | 25 ₽/1000 |
| Google | `/search/xml` | всегда 10 на страницу (с 09.2025), пагинация `page=1,2,…` | 25 ₽/1000 |
| Wordstat New | `/wordstat/new/json` | частотность фразы (`popular[0]`), параметр `regions` | 25 ₽/1000 |

Старый Wordstat API (`/wordstat/json`) мёртв: «Сбор старого вордстата больше не доступен».

Проверка листает страницы **с ранней остановкой**: как только домен найден — глубже
не запрашиваем. Глубина настраивается в проекте (ТОП-10/20/30/50/100).

Ошибки XMLRiver: 15 = «нет результатов» (не ошибка), 110/111 = заняты каналы (ретрай
с паузой), 115/HTTP 429 = перебор потоков (стоп на 10 минут), 200 = кончился баланс,
102–108 = неверные параметры проекта (стоп прогона), «Выполните перезапрос» = ретрай ×3.

## Данные

SQLite-файл: `~/Library/Application Support/SerpDesk/serpdesk.sqlite` (macOS),
`%APPDATA%/SerpDesk/serpdesk.sqlite` (Windows). Держит настройки (user/key XMLRiver),
проекты, фразы и всю историю проверок.

Ежедневные копии лежат в подпапке `backups/`. SerpDesk хранит последние 14 файлов;
восстановление доступно в **Настройки → База данных → Автокопии**.

## Разработка

Node 22 (на этом Mac лежит в комплекте Screaming Frog):

```bash
export PATH="$HOME/.ScreamingFrogSEOSpider/node/5.1/node/bin:$PATH"
cd serpdesk
npm install
npm start          # запуск приложения
npm test           # тесты парсера/матчера (test/parse.test.js)
npm run dist:mac   # сборка dmg+zip (arm64)
npm run dist:win   # сборка setup+portable (x64)
```

`renderer/` открывается и в обычном браузере (мок-режим с демо-данными) — удобно
править вёрстку без Electron: `python3 -m http.server --directory renderer`.

## Структура

- `main.js` — главный процесс: окно, IPC, планировщик автопроверки, CSV, журнал расходов и уведомления
- `lib/analytics.js` — сравнение прогонов, видимость и важные сигналы
- `lib/costs.js` — верхняя оценка запросов и стоимости проверки
- `lib/xmlriver.js` — клиент API: URL-ы, разбор XML, классификация ошибок, punycode-матчер доменов
- `lib/checker.js` — прогон: пул воркеров по фразам, пагинация с ранней остановкой, ретраи
- `lib/db.js` — sql.js (SQLite-wasm), атомарная запись с дебаунсом
- `lib/backups.js` — ежедневные копии базы, ротация и безопасное восстановление
- `renderer/` — интерфейс (vanilla JS, тёмная тема)
