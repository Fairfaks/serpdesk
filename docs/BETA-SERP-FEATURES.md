# Блоки выдачи Яндекса (бета)

Функция включается в настройках проекта только для источника **«Лайв-выдача»**.
SerpDesk добавляет к обычному запросу XMLRiver параметр `additional` и просит вернуть:

- рекламу сверху, снизу и справа;
- колдунщики и боковые колдунщики;
- товарные карусели и цены в магазинах;
- новости;
- граф знаний.

Документация XMLRiver: [параметры API Яндекса](https://xmlriver.com/apiydoc/apiy-about/),
[колдунщики](https://xmlriver.com/apiydoc/apiy-searchsters/),
[реклама](https://xmlriver.com/apiydoc/apiy-adv/).

## Что показывает SerpDesk

Большое число в ячейке остаётся обычной органической позицией. Если XMLRiver
сообщил о центральных блоках выше результата, рядом появляется маленькое `βN` —
приблизительное визуальное место. При наведении показан список найденных блоков.

## Ограничения

- Это не координата в пикселях и не гарантированная копия экрана пользователя.
- Яндекс меняет выдачу по региону, устройству, истории и экспериментам.
- XMLRiver может вернуть не каждый динамический элемент конкретной страницы.
- Боковые блоки и нижняя реклама показываются в подсказке, но не сдвигают
  приблизительное визуальное место.
- Бета не меняет органическую позицию, аналитику ТОП и исторические дельты.

Функция не запрашивает и не сохраняет полный HTML страницы выдачи.
