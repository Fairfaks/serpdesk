# Задача: группировка проектов по домену + порядок дат от новой к старой

Проект: SerpDesk (Electron). Правки только в рендерере `renderer/app.js` и
`renderer/styles.css` (плюс, при желании, состояние сворачивания групп в
localStorage). Node из Screaming Frog:
`export PATH="$HOME/.ScreamingFrogSEOSpider/node/5.1/node/bin:$PATH"`.
Проверка: `node --check renderer/app.js`, `npm test`, `npm start`.

---

## 1. Группировать проекты по домену в сайдбаре

Сейчас `renderSidebar()` рисует плоский список проектов. Нужно сгруппировать их по
полю `project.domain` (оно уже хранится отдельно). Под одним доменом у пользователя
много проектов, разделённых как угодно — по региону ИЛИ по теме/типу запросов:
например `sravni.ru спб`, `sravni.ru ОСАГО`, `sravni.ru кредиты`, `sravni.ru ВЧ`.
Все они с доменом `sravni.ru` попадают в одну группу.

Требования:
- **Заголовок группы** = домен (`sravni.ru`), справа — счётчик проектов в группе.
  Клик по заголовку — свернуть/развернуть группу. Состояние (свёрнута/развёрнута)
  запоминать в `localStorage` по ключу домена, чтобы сохранялось между запусками.
- **Внутри группы** — проекты этой группы. В подписи проекта показывать метку —
  `name` с убранным префиксом-доменом (это может быть регион, тема, тип запросов —
  что угодно, никакой привязки к географии): если `name` начинается с домена
  (без учёта регистра, с/без пробела/дефиса: `sravni.ru спб`, `sravni.ru ОСАГО`),
  показать остаток (`спб`, `ОСАГО`); если после отреза пусто или `name` не
  начинается с домена — показать весь `name`. Рядом мелким — число фраз (как
  текущий `p-count`) и бегущая точка `run-dot`, если проект сейчас проверяется.
- Активный проект (`S.activeId`) подсвечивается как сейчас; клик по проекту — как
  сейчас (переключение).
- Порядок групп — по алфавиту домена; внутри группы — по `name`.
- Домен из одного проекта тоже показывать как группу (единообразно, заголовок с
  доменом всегда). Это ок.
- Ничего не сломать: создание проекта, счётчики, индикатор запущенной проверки,
  сохранение `activeId`.
- Стили выдержать в текущей тёмной теме (см. переменные `--panel/--border-soft/
  --muted` и класс `.proj-item` в `styles.css`). Заголовок группы — компактный,
  с треугольником-стрелкой ▸/▾ состояния.

Подсказка: домены брать из `S.projects` (у каждого есть `.domain`, `.name`,
`.keywordCount`, `.running`, `.id`, `.cfg`). Группировку/рендер делать внутри
`renderSidebar()`; обработчики клика вешать после innerHTML, как уже принято в коде.

## 2. Порядок дат в сетке «Позиции» — от новой к старой (новая слева)

Сейчас в `renderGrid()` столбцы-даты идут слева-направо от старой к новой. Нужно
**развернуть: новейшая дата — крайний левый столбец**, старейшая — справа.

Важно:
- Менять ТОЛЬКО отображение в `renderGrid()` (например, отрисовывать `runs` в
  обратном порядке — `runs.slice().reverse()`), НЕ трогая `getGrid` в main.js:
  виды «Динамика» и «Сравнение» полагаются на хронологический порядок прогонов
  (ось X — старое→новое), их логику и порядок оставить как есть.
- **Дельта (▲N/▼N) в ячейке** считается относительно ПРЕДЫДУЩЕГО по времени
  замера. Сейчас предыдущий столбец — слева. После разворота предыдущий (более
  старый) окажется СПРАВА — соответственно развернуть логику: сравнивать ячейку с
  соседним столбцом-СПРАВА (это более старая дата), направление стрелки/цвет
  сохранить по смыслу (позиция улучшилась = стрелка вверх/зелёная). Значок смены
  URL ◆ и подсветка «не целевой страницы» — сохранить.
- **Автоскролл**: сейчас грид проматывается вправо к новейшей дате. После разворота
  новейшее — слева, поэтому при сортировке по фразе проматывать в начало
  (`scrollLeft = 0`).
- Колонки слева (Фраза, Частота, Показы/Клики/Поз.ПС) — остаются на месте, не
  трогать. Сортировка по клику на столбец-дату — работает по конкретному `run_id`,
  порядок столбцов на неё не влияет.
- Карточки сверху (ТОП-3/10/30, средняя позиция и их дельты) используют «последний
  прогон» = новейший по времени — логику не менять, только визуальный порядок
  столбцов в таблице.

## Проверка

1. `node --check renderer/app.js`, `npm test` — чисто.
2. `npm start`: несколько проектов с одним доменом (напр. `sravni.ru спб`,
   `sravni.ru москва`) собираются в одну группу с заголовком `sravni.ru`,
   сворачивается/разворачивается, состояние помнится после перезапуска.
3. В сетке «Позиции» новейшая дата — крайний левый столбец; стрелки дельт
   считаются корректно (сравнение с более старой датой справа); при импорте
   истории даты тоже идут новая→старая.
